# Contributing

## Development standards

All contributions are expected to:

- Follow the repository's coding conventions.
- Include appropriate automated tests.
- Pass formatting, linting, type checking, and CI.
- Avoid introducing unnecessary dependencies.
- Preserve backwards compatibility unless explicitly approved.
- Include documentation for externally visible behavior changes.

See:
- [Coding standards](docs/development/coding-standards.md)
- [Testing standards](docs/development/testing.md)
- [Architecture](docs/development/architecture.md)

## Pull requests

- Keep PRs focused on one logical change.
- Explain the motivation, not just the implementation.
- Include tests for behavioral changes.
- Resolve all blocking review comments before merge.
- Do not merge with failing required checks.
